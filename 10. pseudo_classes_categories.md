# Categories of CSS Pseudo-Classes

CSS pseudo-classes allow you to apply styles to elements based on their state, position, or user interaction.

## 1. User Action Pseudo-Classes

These are triggered by user interactions.

| Pseudo-Class | Description |
|---------------|-------------|
| `:hover` | Applies styles when the mouse pointer is over an element. |
| `:active` | Applies styles while an element is being clicked. |
| `:focus` | Applies styles when an element receives focus. |
| `:focus-visible` | Applies styles when the browser determines a visible focus indicator is needed. |

### Example

```css
button:hover {
    background-color: blue;
}

button:active {
    transform: scale(0.95);
}

input:focus {
    border: 2px solid green;
}

button:focus-visible {
    outline: 3px solid orange;
}
```

---

## 2. Structural Pseudo-Classes

These select elements based on their position within the DOM tree.

| Pseudo-Class | Description |
|---------------|-------------|
| `:first-child` | Selects the first child element. |
| `:last-child` | Selects the last child element. |
| `:nth-child(n)` | Selects elements based on their position. |
| `:only-child` | Selects an element that is the only child of its parent. |

### Example

```css
li:first-child {
    color: red;
}

li:last-child {
    color: blue;
}

li:nth-child(2) {
    font-weight: bold;
}

p:only-child {
    background-color: yellow;
}
```

---

## 3. Form Validation Pseudo-Classes

These are used with form elements to indicate validation states.

| Pseudo-Class | Description |
|---------------|-------------|
| `:required` | Selects required form fields. |
| `:valid` | Selects inputs whose value is valid. |
| `:invalid` | Selects inputs whose value is invalid. |

### Example

```css
input:required {
    border-left: 4px solid red;
}

input:valid {
    border-color: green;
}

input:invalid {
    border-color: red;
}
```

---

## 4. Form State Pseudo-Classes

These select form controls based on their current state.

| Pseudo-Class | Description |
|---------------|-------------|
| `:checked` | Selects checked radio buttons and checkboxes. |

### Example

```css
input:checked + label {
    color: green;
    font-weight: bold;
}
```

---

## Summary

| Category | Pseudo-Classes |
|-----------|----------------|
| **User Action** | `:hover`, `:active`, `:focus`, `:focus-visible` |
| **Structural** | `:first-child`, `:last-child`, `:nth-child(n)`, `:only-child` |
| **Form Validation** | `:required`, `:valid`, `:invalid` |
| **Form State** | `:checked` |

These are among the most commonly used CSS pseudo-classes and form the core categories for interactive and dynamic styling.
