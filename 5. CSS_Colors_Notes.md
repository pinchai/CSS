# CSS Colors

CSS allows you to specify colors in several ways: - Color Name - RGB -
HEX - HSL - RGBA - HSLA

## 1. CSS Color Names

CSS supports **140 standard color names**.

```css
color: Tomato;
color: Orange;
color: DodgerBlue;
color: MediumSeaGreen;
color: Gray;
color: SlateBlue;
color: Violet;
color: LightGray;
```

Example:

```html
<h1 style="color:Tomato;">Hello World</h1>
```

## 2. CSS Background Color

Use `background-color` to set an element's background.

```html
<h1 style="background-color:DodgerBlue;">Hello World</h1>
<p style="background-color:Tomato;">Lorem ipsum dolor sit amet.</p>
```

## 3. CSS Text Color

Use `color` to change text color.

```html
<h1 style="color:Tomato;">Hello World</h1>
<p style="color:DodgerBlue;">Lorem ipsum dolor sit amet.</p>
<p style="color:MediumSeaGreen;">Another paragraph.</p>
```

## 4. CSS Border Color

```html
<h1 style="border:2px solid Tomato;">Hello World</h1>
<h1 style="border:2px solid DodgerBlue;">Hello World</h1>
<h1 style="border:2px solid Violet;">Hello World</h1>
```

# CSS Color Values

## RGB

```css
background-color: rgb(255, 99, 71);
```

## HEX

```css
background-color: #ff6347;
```

## HSL

```css
background-color: hsl(9, 100%, 64%);
```

## RGBA

```css
background-color: rgba(255, 99, 71, 0.5);
```

## HSLA

```css
background-color: hsla(9, 100%, 64%, 0.5);
```

# \*\*\*\*

- `color` changes text color.
- `background-color` changes background color.
- `border` sets border size, style, and color.
- Colors can be written as Name, RGB, HEX, HSL, RGBA, or HSLA.
- RGBA and HSLA support transparency (`0` transparent, `1` opaque).
