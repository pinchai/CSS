# CSS Backgrounds

CSS **background properties** are used to add background effects to HTML
elements such as `body`, `div`, `p`, and `h1`.

## Main Background Properties

-   `background-color`
-   `background-image`
-   `background-repeat`
-   `background-attachment`
-   `background-position`
-   `background` (shorthand property)

## `background-color`

The `background-color` property sets the background color of an element.

``` css
body {
    background-color: lightblue;
}
```

### Color Values

``` css
background-color: red;
background-color: #ff0000;
background-color: rgb(255,0,0);
```

## Different Elements

``` css
h1 {
    background-color: green;
}

div {
    background-color: lightblue;
}

p {
    background-color: yellow;
}
```

## Opacity / Transparency

The `opacity` property controls transparency.

-   `1` = fully visible
-   `0` = fully transparent

``` css
div {
    background-color: green;
    opacity: 0.3;
}
```

**Note:** This affects the entire element including its text.

## RGBA Transparency

RGBA lets only the background become transparent.

Syntax:

``` css
rgba(red, green, blue, alpha)
```

Example:

``` css
div {
    background: rgba(0, 128, 0, 0.3);
}
```

## Opacity vs RGBA

  Opacity                    RGBA
  -------------------------- ---------------------------------
  Affects whole element      Affects only background
  Text becomes transparent   Text remains visible
  Simple                     Better for readable backgrounds

## Complete Example

``` html
<!DOCTYPE html>
<html>
<head>
<style>
body { background-color: lightblue; }
h1 { background-color: green; }
p { background-color: yellow; }
.box1 {
    background-color: green;
    opacity: 0.3;
}
.box2 {
    background: rgba(0,128,0,0.3);
}
</style>
</head>
<body>

<h1>CSS Background Example</h1>

<p>This paragraph has a yellow background.</p>

<div class="box1">
Using opacity: 0.3 (text is transparent too)
</div>

<br>

<div class="box2">
Using rgba(0,128,0,0.3) (only background is transparent)
</div>

</body>
</html>
```

## Key Points

-   `background-color` sets an element's background color.
-   Colors can be specified with names, HEX, or RGB.
-   `opacity` affects the entire element.
-   `rgba()` affects only the background color.
-   Use `rgba()` when you want transparent backgrounds with readable
    text.
