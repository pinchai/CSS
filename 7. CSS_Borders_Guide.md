# CSS Borders

The **CSS border** properties let you control the **style, width, and
color** of an element's border.

-   A border on all four sides
-   A border on only one side (top, right, bottom, or left)
-   Rounded borders
-   Borders with different colors and styles

Example:

``` css
div {
  border: 2px solid black;
}
```

This creates a **2px solid black border** around the element.

## CSS `border-style`

The `border-style` property specifies **what type of border** to
display.

  Value      Description
  ---------- -------------------
  `dotted`   Dotted border
  `dashed`   Dashed border
  `solid`    Solid line
  `double`   Double line
  `groove`   3D grooved effect
  `ridge`    3D ridged effect
  `inset`    3D inset effect
  `outset`   3D outset effect
  `none`     No border
  `hidden`   Hidden border

## Example

``` css
p.dotted { border-style: dotted; }
p.dashed { border-style: dashed; }
p.solid { border-style: solid; }
p.double { border-style: double; }
p.groove { border-style: groove; }
p.ridge { border-style: ridge; }
p.inset { border-style: inset; }
p.outset { border-style: outset; }
p.none { border-style: none; }
p.hidden { border-style: hidden; }
```

## Multiple Border Styles

``` css
p.mix {
    border-style: dotted dashed solid double;
}
```

Order:

    top right bottom left

-   Top → dotted
-   Right → dashed
-   Bottom → solid
-   Left → double

## Using 1--4 Values

### One value

``` css
border-style: solid;
```

All sides are solid.

### Two values

``` css
border-style: solid dotted;
```

-   Top & Bottom → solid
-   Left & Right → dotted

### Three values

``` css
border-style: solid dotted dashed;
```

-   Top → solid
-   Left & Right → dotted
-   Bottom → dashed

### Four values

``` css
border-style: solid dotted dashed double;
```

-   Top → solid
-   Right → dotted
-   Bottom → dashed
-   Left → double

## Important Note

`border-style` must be set before `border-width` and `border-color` have
any visible effect.

``` css
div {
    border-width: 3px;
    border-color: red;
}
```

Working version:

``` css
div {
    border-style: solid;
    border-width: 3px;
    border-color: red;
}
```

Shorthand:

``` css
div {
    border: 3px solid red;
}
```
