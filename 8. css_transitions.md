# CSS Transitions

CSS transitions allow you to change CSS property values smoothly over a
specified duration instead of changing them instantly.

For example, when a user moves the mouse over an element, its width,
color, or size can gradually change.

------------------------------------------------------------------------

# Basic Syntax

``` css
selector {
    transition: property duration timing-function delay;
}
```

The `transition` property is a shorthand for:

  Property                       Description
  ------------------------------ ------------------------------------------
  `transition-property`          Specifies which CSS property will change
  `transition-duration`          Specifies how long the transition takes
  `transition-timing-function`   Controls the speed curve
  `transition-delay`             Specifies when the transition starts

------------------------------------------------------------------------

# Simple Example

HTML

``` html
<div class="box"></div>
```

CSS

``` css
.box {
    width: 100px;
    height: 100px;
    background-color: red;

    transition: width 2s;
}

.box:hover {
    width: 300px;
}
```

### Result

-   Normal width = `100px`
-   Mouse over → width expands to `300px`
-   Animation takes `2 seconds`
-   Mouse leave → width smoothly returns to `100px`

------------------------------------------------------------------------

# Transition Shorthand

``` css
transition: property duration timing-function delay;
```

Example:

``` css
transition: width 2s ease 0s;
```

Equivalent to:

``` css
transition-property: width;
transition-duration: 2s;
transition-timing-function: ease;
transition-delay: 0s;
```

------------------------------------------------------------------------

# Triggering a Transition

Transitions happen when a property changes. Common triggers include:

### `:hover`

``` css
.box:hover {
    width: 300px;
}
```

### `:focus`

``` css
input:focus {
    border-color: blue;
}
```

### `:active`

``` css
button:active {
    transform: scale(0.9);
}
```

### `:checked`

``` css
input:checked {
    background-color: green;
}
```

------------------------------------------------------------------------

# Transitioning Multiple Properties

``` css
.box {
    transition:
        width 2s,
        height 4s,
        background-color 3s;
}
```

------------------------------------------------------------------------

# Timing Functions

## linear

``` css
transition: all 2s linear;
```

## ease

``` css
transition: all 2s ease;
```

## ease-in

``` css
transition: all 2s ease-in;
```

## ease-out

``` css
transition: all 2s ease-out;
```

## ease-in-out

``` css
transition: all 2s ease-in-out;
```

------------------------------------------------------------------------

# Transition Delay

``` css
.box {
    transition: width 2s 1s;
}
```

------------------------------------------------------------------------

# Using all

``` css
.box {
    transition: all 0.5s ease;
}
```

------------------------------------------------------------------------

# Transform + Transition

### Scale

``` css
.box {
    transition: transform 0.3s ease;
}

.box:hover {
    transform: scale(1.2);
}
```

### Rotate

``` css
.box {
    transition: transform 1s;
}

.box:hover {
    transform: rotate(180deg);
}
```

### Move

``` css
.box {
    transition: transform 0.5s;
}

.box:hover {
    transform: translateX(100px);
}
```

------------------------------------------------------------------------

# Important Note

✅ Put the `transition` property on the original element, not inside
`:hover`.

Correct:

``` css
.box {
    transition: all 0.5s;
}

.box:hover {
    background-color: blue;
    width: 200px;
}
```

Wrong:

``` css
.box:hover {
    transition: all 0.5s;
    background-color: blue;
}
```

# Common Examples

## Button Hover

``` css
button {
    background: blue;
    color: white;
    padding: 12px 20px;

    transition: background-color 0.3s ease;
}

button:hover {
    background: darkblue;
}
```

## Card Shadow Effect

``` css
.card {
    box-shadow: 0 0 5px gray;

    transition: box-shadow 0.3s ease;
}

.card:hover {
    box-shadow: 0 10px 20px gray;
}
```

## Zoom Image

``` css
img {
    transition: transform 0.4s ease;
}

img:hover {
    transform: scale(1.1);
}
```

# Summary

  Property                       Example
  ------------------------------ ---------------------------------------
  `transition-property`          `width`
  `transition-duration`          `2s`
  `transition-timing-function`   `ease-in-out`
  `transition-delay`             `1s`
  Multiple properties            `width 2s, height 1s`
  Animate everything             `all 0.5s ease`
  Common trigger                 `:hover`, `:focus`, `:active`
  Best practice                  Put `transition` in the base selector
