# CSS `position` Property

The **`position`** property controls how an element is placed on a
webpage. It determines whether an element follows the normal document
flow or can be positioned manually using `top`, `right`, `bottom`, and
`left`.

------------------------------------------------------------------------

# Syntax

``` css
selector {
    position: static | relative | absolute | fixed | sticky;
}
```

------------------------------------------------------------------------

# Position Types

## 1. `position: static`

This is the default position for all elements.

### Characteristics

-   Elements follow the normal document flow.
-   Cannot be moved with `top`, `right`, `bottom`, or `left`.
-   Positioned according to the order in the HTML.

### Example

``` css
.box {
    position: static;
    top: 50px; /* Ignored */
    left: 50px; /* Ignored */
}
```

### When to Use

-   Most HTML elements use `static`.
-   No special positioning is needed.

------------------------------------------------------------------------

## 4. `position: fixed`

Positions an element relative to the browser window (viewport).

### Characteristics

-   Removed from normal flow.
-   Remains visible when scrolling.
-   Always stays in the same position.

``` css
.header {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
}
```

### Common Uses

-   Navigation bar
-   Floating button
-   Chat button
-   Back-to-top button

------------------------------------------------------------------------

## 5. `position: sticky`

Behaves like `relative` until reaching a scroll position, then behaves
like `fixed`.

``` css
.menu {
    position: sticky;
    top: 0;
}
```

### Common Uses

-   Table headers
-   Sidebar menu
-   Sticky navigation

------------------------------------------------------------------------

# Positioning Offsets

## top

``` css
top: 20px;
```

## left

``` css
left: 50px;
```

## right

``` css
right: 20px;
```

## bottom

``` css
bottom: 10px;
```

------------------------------------------------------------------------

# z-index

Controls stacking order.

``` css
.box1 {
    position: absolute;
    z-index: 1;
}

.box2 {
    position: absolute;
    z-index: 2;
}
```

Higher values appear on top.

------------------------------------------------------------------------

# Comparison Table

  Property   Normal Flow   Space Reserved   Relative To
  ---------- ------------- ---------------- --------------------------
  static     Yes           Yes              Normal flow
  relative   Yes           Yes              Original position
  absolute   No            No               Positioned ancestor
  fixed      No            No               Browser viewport
  sticky     Yes           Yes              Viewport after scrolling

------------------------------------------------------------------------

# Key Rule

-   static → Normal flow
-   relative → Move from original position
-   absolute → Move relative to parent
-   fixed → Move relative to browser window
-   sticky → Relative first, fixed when scrolling


------------------------------------------------------------------------

## 2. `position: relative`

The element remains in the normal flow, but can be moved relative to its
original position.

### Characteristics

-   Space is still reserved for the element.
-   Moves from its original location.
-   Creates a positioning context for absolute children.

``` css
.parent {
    position: relative;
}

.child {
    position: absolute;
}
```

------------------------------------------------------------------------


------------------------------------------------------------------------

## 3. `position: absolute`

Removes the element from the normal flow and positions it relative to
the nearest positioned ancestor.

### Characteristics

-   No space is reserved.
-   Other elements behave as if it doesn't exist.
-   Uses `top`, `right`, `bottom`, and `left`.

### Example

``` css
.parent {
    position: relative;
}

.child {
    position: absolute;
    top: 20px;
    right: 20px;
}
```

### Common Uses

-   Notification badge
-   Popup
-   Tooltip
-   Dropdown menu
